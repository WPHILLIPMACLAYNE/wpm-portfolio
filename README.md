# WPM.OS — Tactical Interactive Portfolio System

**WPM.OS** é uma experiência de interface tática (FUI) de alta performance, projetada para servir como o dossiê profissional de **Wallace Phillip Maclayne**. Desenvolvido com uma abordagem metalinguística, o sistema explica a si mesmo enquanto demonstra competências em engenharia de software, direção de arte e orquestração de IA.

## 🚀 O Desafio Original (Manifesto)

Este projeto é **100% autoral**. Todo o conceito, projeto, direção criativa e visual foram idealizados do zero absoluto. O objetivo foi lançar um desafio pessoal: criar uma interface de elite sem utilizar recursos prontos, templates ou inspirações existentes para cópia. É a prova real de que a visão humana, quando aliada a agentes de código, pode materializar ideias complexas em sistemas funcionais de altíssimo nível.

## 🛠️ Stack Tecnológico

- **Core:** [Next.js 16](https://nextjs.org/) (App Router) + [React 19](https://react.dev/)
- **Visual & 3D:** [Three.js](https://threejs.org/) + [React Three Fiber](https://r3f.docs.pmnd.rs/) (Renderização Manual de Geometria)
- **Motion:** [Motion (Framer)](https://motion.dev/) para animações de estado e transições espaciais.
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) + CSS Brutalista Customizado.
- **Engenharia:** Arquitetura focada em Performance, Acessibilidade (ARIA) e Pureza de Componentes.

## 💎 Funcionalidades de Elite

- **Boot Sequence Cinematográfico:** Sequência de Power-On Self-Test (POST) simulando inicialização de hardware.
- **Hologramas 3D Dinâmicos:** Artefatos em wireframe que representam cada subsistema em tempo real.
- **Navegação Espacial (Windows+Tab Style):** Transições laterais inteligentes que calculam a direção do fluxo de dados.
- **Células de Comando com LED:** Header e Menu Mobile com indicadores de estado físicos e feedback tátil.
- **Efeito CRT & Glitch:** Imersão total através de scanlines persistentes e distorção tática em elementos de alta prioridade.
