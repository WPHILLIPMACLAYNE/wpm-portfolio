# AI_CONTEXT.md - Contexto do projeto para Codex

## Objetivo
Criar um portfólio pessoal/profissional premium, visualmente forte, tecnicamente limpo e pronto para publicação. O projeto deve ser tratado como uma vitrine de alto nível, não como um SaaS, marketplace ou aplicação empresarial.

## Tipo de produto
Portfólio criativo/profissional com foco em:

- apresentação pessoal;
- projetos/cases;
- habilidades;
- serviços;
- contato;
- impacto visual;
- animações e microinterações;
- performance;
- responsividade;
- SEO técnico.

## O que este projeto NÃO deve virar sem aprovação

- SaaS;
- dashboard complexo;
- sistema com usuários;
- rede social;
- e-commerce;
- blog/CMS pesado;
- aplicação full-stack sem necessidade;
- projeto dependente de muitos serviços pagos.

## Referências de qualidade
O projeto deve buscar o nível de acabamento de portfólios como:

- sites simples premium feitos em Framer: foco em identidade, tipografia e motion;
- portfólios em Astro/GSAP/Lenis: foco em front-end criativo, performance e código limpo;
- portfólios audiovisuais: cuidado com vídeos, thumbnails, loaders e player;
- portfólios WebGL/3D: usar apenas se houver propósito real e performance aceitável.

Não copiar layout, animação, marca ou assets de terceiros. Usar as referências apenas como régua de qualidade.

## Escopo recomendado para lançamento

### Obrigatório
- Página inicial com hero forte.
- Seção sobre/perfil.
- Seção de projetos/cases.
- Seção de habilidades/serviços.
- Seção de contato.
- Página ou estado 404 customizado.
- SEO técnico básico.
- Responsividade total.
- Acessibilidade básica.
- Performance aceitável.
- Deploy em domínio público.

### Opcional
- Animações avançadas.
- Scroll suave.
- Cursor/mouse effects.
- Página individual por projeto.
- Showreel ou vídeo curto.
- WebGL/3D.
- Área privada para cases sensíveis.
- Formulário com backend.
- Analytics.
- Observabilidade.

### Deve ser evitado no início
- Banco de dados sem necessidade.
- CMS pesado antes de definir conteúdo.
- Login sem área privada real.
- WebGL decorativo que prejudique mobile.
- Vídeos enormes sem compressão.
- Muitas bibliotecas de animação ao mesmo tempo.

## Arquitetura mental correta
Para um portfólio premium, o resultado depende mais de:

1. direção visual;
2. conteúdo bem organizado;
3. front-end bem executado;
4. motion com bom gosto;
5. assets otimizados;
6. deploy estável;
7. QA;
8. SEO;
9. acessibilidade.

Backend só entra quando houver necessidade funcional real.

## Critérios de aceite visual
- O site precisa parecer intencional, não apenas funcional.
- A tipografia deve ter hierarquia clara.
- O espaçamento precisa ser consistente.
- As animações devem ter ritmo e não atrapalhar leitura.
- O mobile não pode ser uma versão quebrada do desktop.
- O carregamento inicial precisa ser controlado.
- O contato precisa estar óbvio.

## Critérios de aceite técnico
- Build sem erros.
- Sem segredos no repositório.
- Sem warnings graves de acessibilidade.
- Imagens e vídeos otimizados.
- Dependências justificadas.
- Código organizado por componentes/seções.
- CSS sustentável.
- Metadados SEO presentes.
- Página 404 funcionando.
- Deploy reproduzível.
